# Minidash 重构设计交付物

本次重构针对现有 `web-admin`（React 19 + Tailwind v4 + Radix）与 `web-theme`（工控状态页）两套前端，
输出一份可直接评审的高保真交互效果图，以及一套可计算的色彩与设计规范。

## 文件

| 文件 | 内容 | 打开方式 |
|---|---|---|
| `design-system.html` | 品牌与色彩体系规范（12 章）：设计原则、品牌色阶、中性色阶、语义令牌、状态色、可视化色序、字体、间距圆角、动效、组件、无障碍、信息架构 | 浏览器直接打开 |
| `prototype.html` | 可交互效果图：公开状态页 / 节点详情 / 控制台（节点管理、网络探测、告警、数据、设置、更新） | 浏览器直接打开 |

两个文件都是**零依赖单文件**——不引用 CDN、不加载外部字体与图片。
现有的 4 个 `prototype-*.html` 依赖 `cdn.tailwindcss.com`，在内网或离线环境会直接白屏，
这与 Minidash「自托管、数据私有」的定位冲突，本次刻意规避。

### 交互清单

- 顶部控制条切换三个场景；`#console:probe` 这类 hash 可直达子页面
- 深色 / 浅色切换（瞬时切换，不闪白），`?theme=light` 可指定
- 公开页：分组筛选、搜索过滤、点击节点卡片进入详情、拓扑图节点点击
- 详情页：CPU / 内存 / 网络切换、1H–30D 时间范围、图表十字准线与数值提示
- 控制台：侧栏 8 个入口、表格搜索、行悬停操作、开关、`⌘K` 命令面板
- 规范页：品牌色四向试穿（蓝 / 紫 / 青 / 琥珀）实时改全局强调色

## 核心设计决策

**1. 品牌色定为 Signal Blue `#2B63F5`**
原项目两套前端都只有中性灰（`web-theme` 用 macOS 灰，`web-admin` 用 shadcn 默认灰蓝），
没有任何品牌识别。新色与状态绿（150°）、琥珀（75°）、红（25°）保持足够色相距离，
在红绿色盲模拟下仍可区分。

500 档原本取 `#2F6BFF`，实测白字对比度 4.46:1，未达 AA 正文标准；微调至 `#2B63F5` 后为 **4.99:1**。
同时把「品牌色」与「实心按钮底色」拆成 `--brand` 与 `--brand-solid` 两个令牌：
深色模式下按钮用 `#2B63F5` 保证白字可读，而文字、图形、焦点环用更亮的 `#5D89FF`。

**2. 离线用灰，不用红**
现有实现已经是这个方向（`--offline` 为中性灰），本次把它上升为规范条文：
红只留给「故障 / 超限」，离线是「没有数据」，两者混用会让真正的故障失去分量。

**3. 3D 地球改为 2D 节点拓扑**
`web-theme` 的 `Globe.tsx` 用 three.js 渲染 3D 地球，首屏成本与「极致轻量」的定位相悖；
自绘世界地图又涉及地图合规问题。改为纯 SVG 的同心环拓扑：Hub 居中，节点按延迟着色，
连线用二次贝塞尔成弧，光点沿路径流动。约 100 行 JS，无第三方依赖。

**4. 信息架构从 8 项平铺改为 3 组任务域**
监控（节点 / 探测）、运营（告警 / 数据）、系统（外观 / 安全 / 设置 / 更新）。
原侧栏把「节点管理」和「版本更新」并列，权重失真。

**5. 品牌色面积不超过 10%**
表格里的指标条用中性灰，只有越过阈值才转琥珀 / 红；节点卡片的分组标签也用灰色徽章而非品牌色。
品牌色只出现在主按钮、当前导航项、焦点环、实时数据点。

## 令牌落地

规范里的语义变量可直接映射到 Tailwind v4 的 `@theme`：

```css
/* web-admin/src/index.css 与 web-theme/src/index.css 共用 */
@theme inline {
  --color-bg: var(--bg);
  --color-surface: var(--surface);
  --color-surface-2: var(--surface-2);
  --color-line: var(--line);
  --color-line-soft: var(--line-soft);
  --color-text: var(--text);
  --color-text-2: var(--text-2);
  --color-text-3: var(--text-3);
  --color-brand: var(--brand);
  --color-brand-solid: var(--brand-solid);
  --color-ok: var(--ok);
  --color-warn: var(--warn);
  --color-crit: var(--crit);
  --color-off: var(--off);
}
```

`prototype.html` 顶部的 `:root` / `:root[data-theme="light"]` 两块就是完整的变量清单，可直接复制。
现有 `web-admin` 的 `--primary` 等 shadcn 变量保留不动，只新增上述语义层，避免一次性改动过大。

组件层建议按「规范 §10」重写三个基础件即可覆盖 80% 界面：`Button`、`Badge`、`Card`。
表格的指标单元格（`metric-cell`）与图表工具条是本次新增的两个结构件。

## 未覆盖

- 登录页与首次引导流程
- 移动端断点只做到 1024 / 620 两级，未做 375px 专项
- 主题市场（`/admin/themes`）的多主题预览
- 动效只给了曲线与时长，未提供 Lottie / 帧动画资源
