# 2026-10-28

## Minidash 重构设计交付（redesign/）

产出两个零依赖单文件 HTML，用于 web-admin + web-theme 的视觉重构评审：

- `redesign/design-system.html` — 品牌与色彩规范，12 章（原则/品牌色/中性色/语义令牌/状态色/可视化/字体/间距圆角/动效/组件/无障碍/信息架构）
- `redesign/prototype.html` — 可交互效果图：公开状态页、节点详情、控制台 6 个子页面、⌘K 命令面板
- `redesign/README.md` — 设计决策与 Tailwind 令牌落地说明

### 关键决策（后续实现需沿用）

1. **品牌色 Signal Blue `#2B63F5`**（原方案 `#2F6BFF` 白字对比度 4.46 未达 AA，微调后 4.99）。
   拆分两个令牌：`--brand`（文字/图形/焦点环，深色用 `#5D89FF`）与 `--brand-solid`（实心按钮底，恒为 `#2B63F5`）。
2. **离线用灰不用红**：红只留给故障/超限，离线是「无数据」。现有 `--offline` 已是中性灰，本次上升为规范。
3. **3D 地球（Globe.tsx / three.js）改为纯 SVG 同心环拓扑**：轻量 + 规避地图合规风险。
4. **信息架构 8 项平铺 → 3 组**：监控（节点/探测）、运营（告警/数据）、系统（外观/安全/设置/更新）。
5. **品牌色面积 ≤ 10%**：表格指标条用中性灰，越阈值才转琥珀/红。

### 技术注意事项（踩过的坑）

- 现有 4 个 `prototype-*.html` 依赖 `cdn.tailwindcss.com`，内网白屏；新交付物全部内联 CSS，无外部依赖。
- 主题切换必须在切换瞬间禁用 transition（`web-theme/src/App.tsx` 的 useTheme 已有此做法），否则颜色会停在中间态闪白。
- 图表 viewBox 宽度需按容器实际像素设置（1:1），否则 `preserveAspectRatio="none"` 会把文字拉变形。
- 页面内 `display:none` 的场景中初始化图表会拿到宽度 0，切场景时需 `requestAnimationFrame` 重绘。
- CSS 类名 `.sw` 在规范页同时被「开关」和「色板格」使用会串样式，色板已改名 `.cell`。
